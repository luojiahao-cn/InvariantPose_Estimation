# 磁主轴估计算法对比分析 (Algorithm Comparison for Principal Axis Estimation)

本文档总结了 SCA、TR、RO 和 SSL 四种算法在磁偶极子主轴估计任务中的技术细节、差异以及实验表现分析。

---

## 1. 算法核心机制概览

| 算法 | 核心机制 | 迭代形式 | 计算复杂度 |
| :--- | :--- | :--- | :--- |
| **SCA (Successive Convex Approximation)** | 主函数最小化 (MM) | 每步求解一个精确的球面信赖域子问题 (TRS) | 高 (涉及矩阵特征分解) |
| **TR (Trust Region)** | 流形信赖域 | 在切空间内使用 Steihaug-TCG 寻找最优下降方向 | 高 (涉及 Hessian-vector 乘法) |
| **RO (Riemannian Optimization)** | 流形梯度下降 | 沿黎曼梯度方向进行线搜索或 BB 步长更新 | 中 |
| **SSL (Successive Semidefinite Lifting)** | 近端线性化 / 幂迭代 | 梯度步长 + 近端项 + 直接归一化投影 | 极低 |

---

## 2. 核心差异对比

### TR vs. RO (二阶与一阶之争)
*   **RO** 是**一阶方法**，类似于在球面上“走步”，只看当前的坡度（梯度）。
*   **TR** 是**二阶方法**，它通过 Riemannian Hessian 捕捉球面的曲率信息，理论上在极值点附近收敛更快、更准，但计算量大，且高度依赖信赖半径的设置。

### SCA vs. SSL (结构化与通用性之争)
*   **SCA** 试图通过构造原函数的**全局上界二次代理**来保证单调下降。它非常稳健，但每一步都需要调用复杂的 TRS 求解器。
*   **SSL** 放弃了复杂的二阶构造，采用**近端线性化**。它的迭代公式类似于求解特征向量的“幂迭代”，计算极其简单。

---

## 3. 为什么 SSL 是 RO 的一个特例？

从数学推导上看，SSL 实际上是**固定参数化**的 RO。
*   **RO 步长公式**：$r_{new} = \text{normalize}\left( -\nabla f(r) + (\frac{1}{\eta} + r^T \nabla f)r \right)$
*   **SSL 步长公式**：$r_{new} = \text{normalize}\left( -\nabla f(r) + \beta_{prox} r \right)$

当 SSL 的近端参数 $\beta_{prox} = \frac{1}{\eta} + r^T \nabla f$ 时，两者完全等价。SSL 通过固定一个较大的 $\beta_{prox}$，省去了复杂的投影计算和步长搜索，提供了一种更高效的迭代动态。

---

## 4. 实验结果分析：为什么 SSL 表现最优？

在特定实验中，SSL 的误差（$0.037$）优于 RO（$0.083$）和 SCA（$0.18$），原因如下：

### 1) 步长稳定性 (Step-size Stability)
RO 使用的 BB 步长在非凸球面上容易产生剧烈波动，可能导致算法跳过全局最优解而陷入较浅的局部极小值。SSL 的 $\beta_{prox}$ 相当于提供了一个**自带正则化的小步长**，在复杂的非凸地形中滑行更稳。

### 2) 隐式正则化 (Implicit Regularization)
SSL 在归一化前保留了梯度的“径向”信息，这种类似于**正则化幂迭代**的行为与主轴估计（寻找特征方向）的物理本质高度契合，比纯粹在切空间运动的 RO 更容易捕捉到物理真实的轴向。

### 3) 局部极小值规避 (Local Minima Avoidance)
SCA 这种收敛极快的二阶方法，在初始点较差时，极易瞬间收敛到附近的局部极小值。SSL 的“慢而稳”迭代特性赋予了它一定的全局搜索能力，能够绕过某些伪极值点。

---

## 结论建议
- **追求极速与嵌入式实现**：首选 **SSL**。
- **通用流形优化研究**：使用 **RO**。
- **精简算法库**：建议保留 **SSL** 作为主轴估计的默认算法，保留 **RO** 作为基准参照，可考虑舍弃复杂的 **TR**。
